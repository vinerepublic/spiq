# Privacy Policy for Spiq

**Last Updated:** 2026-05-17

## Overview

Spiq is a mobile companion app for self-hosted OpenClaw AI agents. This privacy policy explains how the app handles user data.

## Data Collection

### What We Collect

Spiq collects minimal data necessary for operation:

1. **Gateway Connection Information**
   - Gateway URL (user-provided)
   - Authentication tokens (generated by your Gateway)
   - Agent and session IDs

2. **Voice Data**
   - Microphone audio (processed in real-time, not stored by Spiq)
   - Voice transcripts (stored temporarily in session history)

3. **Device Information**
   - Device model and OS version (for debugging)
   - App version and build number

### What We Do NOT Collect

- Personal identifying information (name, email, phone number)
- Location data
- Contacts or photos
- Payment information
- Analytics or tracking data (no third-party analytics)

## Data Usage

### How We Use Your Data

1. **Gateway Connection**: Connection details are stored locally in encrypted storage to maintain your session
2. **Voice Conversations**: Audio is processed for speech recognition and sent to your self-hosted Gateway
3. **Session History**: Conversation transcripts are stored locally for reference

### Data Storage

- All data is stored **locally on your device** using encrypted storage (iOS Keychain / Android KeyStore)
- No data is sent to Spiq servers (we don't have servers)
- Conversation data is sent **only to your self-hosted Gateway** that you configure

## Third-Party Services

Spiq may communicate with the following services based on your configuration:

### Your Self-Hosted Gateway (Required)
- Purpose: AI agent communication
- Data Shared: Voice audio, messages, session data
- Privacy: Controlled by you (self-hosted)

### OpenAI API (Optional - when using OpenAI Realtime transport)
- Purpose: Real-time voice conversation processing
- Data Shared: Voice audio, conversation context
- Privacy: Subject to [OpenAI Privacy Policy](https://openai.com/policies/privacy-policy)
- Note: Only used if you configure this transport method

### LiveKit (Optional - when using LiveKit transport)
- Purpose: Low-latency voice session infrastructure
- Data Shared: Voice audio streams
- Privacy: Self-hosted or subject to LiveKit hosting terms
- Note: Only used if your Gateway configures this transport

## Data Retention

- **Local Storage**: Data remains on your device until you delete it
- **Voice Sessions**: Active session data is cleared when you end a session
- **Conversation History**: Stored locally until you manually delete it
- **Authentication Tokens**: Stored until you disconnect from Gateway

## User Rights

You have full control over your data:

1. **Access**: View all conversation history in the app
2. **Delete**: Clear individual conversations or all data
3. **Export**: Not currently supported (coming in future version)
4. **Disconnect**: Remove all Gateway connection data at any time

## Security

We take security seriously:

- All sensitive data encrypted at rest using platform-secure storage
- HTTPS required for Gateway connections (in production)
- No hardcoded API keys in production builds
- Server-side ephemeral token generation (recommended)

## Permissions

Spiq requests the following device permissions:

### Microphone (Required)
- **Purpose**: Record voice for conversations with AI agents
- **When**: Only during active voice sessions
- **Storage**: Audio processed in real-time, not stored

### Camera (Optional)
- **Purpose**: Scan QR codes for Gateway pairing
- **When**: Only when you use QR pairing feature
- **Storage**: Not stored, processed locally

### Speech Recognition (Required on Android)
- **Purpose**: Convert speech to text
- **When**: During voice conversations
- **Storage**: Not stored by Spiq

## Children's Privacy

Spiq is not intended for children under 13. We do not knowingly collect data from children.
